# 💡 Идеи и План Доработок (Roadmap): ShutdownTimerPro (v0.1.0-alpha)

В данном документе представлена структурированная карта развития приложения **ShutdownTimerPro**, включая задачи по безопасности, стабильности, расширению интерфейса и разработке умных защитных режимов (Smart Guard).

---

## 🛡️ 1. Безопасность и Стабильность (Приоритет: Высокий / High Priority)

### 1.1. Single Instance Lock (Защита от повторного запуска)
- [x] **Защита от дубликатов процессов**: Реализован механизм блокировки через локальный сокет `127.0.0.1:49812`.
- [x] **Фокусировка окна**: При запуске второго экземпляра отправляется сигнал существующему процессу для разворачивания и фокусировки окна.

### 1.2. Гарантированная отмена выключения и чистка потоков
- [x] **Авто-отмена при закрытии**: При закрытии окна (`window.events.closed`) автоматически выполняется `shutdown -a` при активном таймере.
- [x] **Остановка фоновых потоков**: Завершение активных потоков проверки (CPU Guard, Process Guard, Network Guard) через `threading.Event`.

### 1.3. Строгая валидация пользовательского ввода и защиты API
- [x] **Проверка параметров в `CyberAPI`**: Валидация `mode` (`shutdown`, `restart`, `sleep`, `lock`) и времени $0 \le t \le 86400$.
- [x] **Защита от невалидного ввода**: Возврат ошибок валидации в интерфейс с фильтрацией аргументов.

### 1.4. Обработка прав Администратора и системных ошибок
- [x] **Перехват ошибок `subprocess`**: Добавлена обработка `PermissionError` и `CalledProcessError` при системных командах.
- [x] **Уведомление пользователя**: Отображение всплывающих уведомлений (Toast) в HUD-интерфейсе при недостаточности прав.

### 1.5. Локальный аудит событий (Security Audit Log)
- [x] **Журналирование действий**: Запись в `app.log` событий создания, отмены таймеров, ошибок и действий Smart Guard.

---

## 🎨 2. Интерфейс, UX и Уведомления (Приоритет: Средний / Medium Priority)

### 2.1. Сворачивание в системный трей (System Tray Icon)
- [x] **Интеграция с треем**: Реализовано сворачивание в трей Windows через `pystray`.
- [x] **Контекстное меню и подсказки**: Отображение состояния в всплывающей подсказке и меню "Показать HUD / Отменить таймер / Выйти".

### 2.2. Управление звуковыми эффектами
- [x] **Переключатель звука (Mute/Unmute)**: Добавлена кнопка 🔊/🔇 с сохранением настройки в профиле `timer_cyber_prefs.json`.
- [x] **Аудио-оповещения**: Звуковые бипы отсчета за 10 секунд до срабатывания действия.

### 2.3. Горячие клавиши (Hotkeys)
- [x] **Управление с клавиатуры**: Назначение `Space` (старт/пауза) и `Esc` (отмена таймера) при активном окне.

### 2.4. Безопасное сохранение состояния UI
- [x] **Валидация JSON файла**: Обработка ситуаций, когда файл настроек `timer_cyber_prefs.json` поврежден (сброс к дефолтным значениям).

## ⚙️ 3. Умные режимы (Smart Guard) и Мониторинг (Приоритет: Средний / Medium Priority)

### 3.1. Process Guard (Завершение по процессу)
- [x] **Мониторинг процесса**: Завершение работы после закрытия указанного процесса (например, `game.exe`).
- [x] **Интерфейс выбора**: Выпадающий список с динамическим сканированием активных `.exe` процессов.

### 3.2. Network Guard (Завершение по сетевой активности)
- [x] **Отслеживание загрузок**: Выключение ПК при снижении сетевого трафика ниже порога (< 100 КБ/с).

### 3.3. Hardware Safety Guard (Защита оборудования)
- [ ] **Мониторинг температур**: (Опционально) экстренное или плановое выключение при превышении критической температуры CPU/GPU.

---

## 📦 4. Сборка, Дистрибуция и CI/CD (Приоритет: Низкий / Low Priority)

### 4.1. Автоматизация сборок (GitHub Actions)
- [ ] **CI/CD Pipeline**: Создать GitHub Action Workflow для автосборки standalone `.exe` с помощью PyInstaller при создании нового тега/релиза в репозитории.

### 4.2. Контроль целостности
- [ ] **Хеширование релизов**: Публикация SHA-256 хешей `.exe` файлов на странице релизов для проверки безопасности скачанного дистрибутива.
