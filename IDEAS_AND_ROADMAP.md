# 💡 Идеи и План Доработок: ShutdownTimerPro (v0.1.0-alpha)

В этом документе собраны все важные идеи по безопасности, доработкам и расширению функционала приложения **ShutdownTimerPro**.

---

## 🛡️ 1. Безопасность и Стабильность (Приоритет: Высокий)

- [ ] **Single Instance Lock (Защита от повторного запуска)**:
  - Использовать `NamedMutex` или сокет-лок в Python, чтобы при попытке открыть второй `.exe` программа фокусировала уже запущенное окно, а не создавала дубликат процесса.
- [ ] **Гарантированная отмена выключения при выходе**:
  - При закрытии окна программы (нажатие `✕` или `Alt+F4`) во время активного таймера — автоматически выполнять `shutdown -a` и сбрасывать активные защитные потоки.
- [ ] **Валидация пользовательского ввода**:
  - Запретить ввод отрицательных значений часов и минут, добавить ограничение по максимуму (например, 24 часа).
- [ ] **Обработка прав Администратора**:
  - Перехватывать возможные ошибки выполнения системной команды `shutdown` в случае ограниченных прав пользователя Windows.

---

## 🎨 2. Интерфейс и UX (Приоритет: Средний)

- [ ] **Сворачивание в системный трей (System Tray Icon)**:
  - Добавить возможность сворачивать приложение в трей возле часов вместо полного закрытия, с отображением остатка времени при наведении мыши.
- [ ] **Звуковые уведомления при старте/финише**:
  - Добавить переключатель звуковых эффектов (Mute/Unmute) для Web Audio синтезатора.
- [ ] **Горячие клавиши (Hotkeys)**:
  - Назначить клавишу `Space` для паузы/запуска таймера и `Esc` для отмены.

---

## ⚙️ 3. Умные режимы (Smart Guard)

- [ ] **Process Guard (Отслеживание процесса игры/программы)**:
  - Реализовать функцию выключения ПК сразу после того, как завершится указанный процесс (например, `game.exe` или `render.exe`).
