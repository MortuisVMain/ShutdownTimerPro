# 💡 Идеи и План Доработок (Roadmap): ShutdownTimerPro

В данном документе представлена структурированная карта развития приложения **ShutdownTimerPro**, включая задачи по безопасности, стабильности, расширению интерфейса и разработке умных защитных режимов (Smart Guard).

---

## 🛡️ 1. Безопасность и Стабильность (Приоритет: Высокий / High Priority)

### 1.1. Single Instance Lock (Защита от повторного запуска)
- [x] **Защита от дубликатов процессов**: Реализован атомарный Win32 Named Mutex (`Global\ShutdownTimerPro_...`) с поддержкой `SO_REUSEADDR` IPC для разворачивания окна.
- [x] **Фокусировка окна**: При повторном запуске отправляется сигнал существующему процессу для фокусировки окна.

### 1.2. Гарантированная отмена выключения и чистка потоков
- [x] **Авто-отмена при закрытии**: При закрытии окна (`window.events.closed`) вызывается `abort_shutdown()` (`shutdown -a`).
- [x] **Остановка фоновых потоков**: Корректное завершение потоков проверки (CPU Guard, Process Guard, Network Guard) через `threading.Event`.

### 1.3. Строгая валидация пользовательского ввода и защиты API
- [x] **Проверка параметров в `TimerEngine`**: Валидация режимов (`shutdown`, `restart`, `sleep`, `lock`, `monitor`) и времени.
- [x] **Единый источник правды (Single Source of Truth)**: Перенос счетчика таймера из JS в Python Core, предотвращение троттлинга Webview2 при минимизации.

### 1.4. Безопасный Snooze (+5 / +10 / +15 мин)
- [x] **Переназначение системного таймера**: Функция `snooze()` вызывает `abort_shutdown()` и повторно планирует системную команду Windows с новым остатком времени.

### 1.5. Локальный аудит событий (Security Audit Log)
- [x] **Журналирование действий**: Запись в `app.log` событий создания, отмены таймеров, ошибок и действий Smart Guard без пустых `except: pass`.

## 🎨 2. Интерфейс, UX и Уведомления (Приоритет: Средний / Medium Priority)

### 2.1. Сворачивание в системный трей (System Tray Icon)
- [x] **Интеграция с треем**: Реализовано сворачивание в трей Windows через `pystray`.
- [x] **Контекстное меню и подсказки**: Отображение состояния в всплывающей подсказке и меню "Показать HUD / Отменить таймер / Выйти".

### 2.2. Управление звуковыми эффектами
- [x] **Переключатель звука (Mute/Unmute)**: Кнопка 🔊/🔇 с сохранением настройки в профиле `timer_cyber_prefs.json`.
- [x] **Аудио-оповещения**: Звуковые бипы обратного отсчета за 10 секунд до срабатывания действия.

### 2.3. Горячие клавиши (Hotkeys)
- [x] **Управление с клавиатуры**: Назначение `Space` (старт/пауза) и `Esc` (отмена таймера) при активном окне.

### 2.4. Режим «В точное время» (Wall-Clock Mode)
- [x] **Выключение по расписанию**: Переключатель `[ЧЕРЕЗ ВРЕМЯ]` / `[В ТОЧНОЕ ВРЕМЯ]` (например, в 02:30 с автоматическим переходом через полночь).

### 2.5. Нативный Drag и Оффлайн-устойчивость
- [x] **Плавное перемещение**: Интеграция `-webkit-app-region: drag` для заголовка.
- [x] **Оффлайн-шрифты**: Fallback на системные шрифты (`Segoe UI Variable`, `Consolas`) без мигания при отсутствии интернета.

## ⚙️ 3. Умные режимы (Smart Guard) и Управление питанием

### 3.1. Process Guard (Завершение по процессу)
- [x] **Мониторинг процесса**: Завершение работы после закрытия указанного процесса (с перехватом `NoSuchProcess`/`AccessDenied`).
- [x] **Интерфейс выбора**: Выпадающий список с динамическим сканированием активных `.exe` процессов.

### 3.2. Network Guard (Завершение по сетевой активности)
- [x] **Отслеживание загрузок**: Выключение ПК при снижении сетевого трафика ниже порога (< 100 КБ/с).

### 3.3. Действие «Выключить только мониторы»
- [x] **SC_MONITORPOWER**: Режим `ЭКРАН` (`SendMessage SC_MONITORPOWER, 2`) для гашения дисплеев во время рендера или скачивания без сна ПК.

### 3.4. Режим Caffeine / Keep-Awake
- [x] **Защита от сна ОС**: Win32 `SetThreadExecutionState` для предотвращения автоматического засыпания Windows во время активной задачи.
