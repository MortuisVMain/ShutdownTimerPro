# ADR 001: Переход на Python Core Timer Engine и нативные Win32 API

## 📌 Статус
Принято (Accepted) — v0.2.0-alpha

## 🎯 Контекст (Context)
В ранних версиях (v0.1.0 – v0.1.1) логика обратного отсчета выполнялась в JavaScript фронтенда через `setInterval(1000)`, в то время как команда `shutdown -s -t` параллельно передавалась Windows.
Это приводило к следующим критическим дефектам:
1. При минимизации или потере фокуса движок Webview2 троттлит фоновые JS-интервалы, вызывая рассинхрон таймера интерфейса с ядром Windows.
2. При нажатии Snooze (+5 мин) JS увеличивал только локальную переменную, не переназначая таймер в Windows, что вызывало преждевременное выключение ПК.
3. Блокировка процесса через сокет `127.0.0.1:49812` могла зависать в `TIME_WAIT` после сбоев.

## 💡 Архитектурное решение (Decision)
1. **Единый источник правды (Single Source of Truth)**:
   Таймер полностью перенесён в Python (`TimerEngine`). Фронтенд работает в чисто реактивном режиме, опрашивая `get_timer_state()` каждые 500 мс.
2. **Безопасный Snooze**:
   При добавлении времени ядро автоматически вызывает `PowerManager.abort_shutdown()` (`shutdown -a`) и переназначает команду с обновленным остатком секунд.
3. **Win32 Named Mutex**:
   Вместо локального TCP сокета применен нативный `CreateMutexW(None, False, "Global\\ShutdownTimerPro_...")`, исключающий коллизии портов и задержки `TIME_WAIT`.
4. **Win32 Power Primitives**:
   - Гашение мониторов через `SendMessage(HWND_BROADCAST, WM_SYSCOMMAND, SC_MONITORPOWER, 2)`.
   - Режим Caffeine / Keep-Awake через `SetThreadExecutionState`.
5. **Поддержка режима «В точное время»**:
   Добавлен расчет времени до целевого часа/минуты (`at_time`), включая переход через полночь.

## ⚖️ Оценка компромиссов (Consequences & Trade-offs)
- **Плюсы**:
  - 100% гарантия точности таймера вне зависимости от состояния окна Webview.
  - Полноценная поддержка гашения дисплеев и запрета на сон во время рендера.
  - Мгновенная атомарная проверка единственного экземпляра.
- **Компромиссы**:
  - Вызовы Win32 `SendMessageW` и `CreateMutexW` привязаны к платформе Windows (что соответствует целевой ОС утилиты).
